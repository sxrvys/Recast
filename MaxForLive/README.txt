RECAST — SAMPLE COLLAGE / SMART SEQUENCER

START
Load Recast on one MIDI track in Live. Its compact 200px device strip opens the instrument with Open Recast. The editor does not open automatically.
The workshop opens on the collage page. New instances load a starter kit automatically. Press Play, or Generate and then Play. Drop recordings onto the layer names, or use Browse. Generate builds an arrangement from source fragments rather than playing the original recording straight through.

COLLAGE
Four main controls shape Density, Fragment size, Movement and Damage. Choose a style to fill the sliders once, then adjust them and click Generate. New rhythm changes placements; New cuts changes source regions without replacing the rhythm; Shuffle fragments swaps the regions assigned to events. New damage rerolls treatment from a retained base, without recursively multiplying repeats.
Library folder selects a local sample/music directory. New sounds from library indexes supported files and draws sources for unlocked layers. Stop cancels scanning/preparation. Advanced allows additional library roots. Up to 50,000 files are indexed; full recordings decode into memory, so begin with modest collections of short recordings. Nothing is uploaded or downloaded.
Each ring is a layer; dots mark event starts and arcs show gates. Up to 24 layers, 16 source files per layer, 256 candidate cuts per layer and 1024 events per phrase are supported. Layer controls include mute, solo and lock. Lock preserves a layer through regeneration. Layer / advanced opens Audio, Cut, Envelope, Rhythm, Structure, FX and Pitch sections. Audio offers local-library duration filters and the number of unlocked layers to refill. Cut offers a dual-handle cut duration range for random windows, equal divisions, energy-onset cuts and full-source playback. Envelope has an independent playback-gate range plus fades and choking. Rhythm and Structure control event count, strong-beat pull, recurring motifs, gaps and per-loop probability. FX separates rhythmic damage from optional flutter, low/high-pass filters, bit reduction, drive, flanging, echo and reverb, with processing probability and strength controls. Manage source pool shows each recording with Hear, Remove and weight controls, plus weighted, cycle and shuffled ordering.
Keep stores a complete source-aware phrase in one of four slots. Compatible source-aware Keeps prepare in the background while the current phrase plays, then swap at the next ready bar without stopping the engine. Changed kits or cold source files can still need preparation. Commit take fixes the current probability/voice-limit realization. Loop WAV produces the complete loop. Layer stems writes one stereo WAV per source layer, an aligned full mix and an export manifest. The files share a start, length and gain, so they recombine correctly. Rendering yields between blocks; Stop cancels it. Cancelled exports leave partial WAVs at the chosen destination. Recast processing is included; downstream Live FX are not. Rendered-sound MIDI export assigns different processed fragments to different notes; ordinary role-kit MIDI does not reproduce all source-region decisions.
Pitch offers two approaches. Fragment correction estimates simple periodic notes. Recording key sync uses spectral chroma across several windows to estimate a whole recording's key, then transposes confident sources toward a shared target. Auto picks the target from confident audible sources. Manual uses the selected root/scale. Relative major/minor families align without changing chord intervals. Ambiguous recordings stay untuned. Manage source pool → the key button on each recording lets you override a key, leave that source untuned, or return to analysis. Key estimates can be wrong, particularly with noise, changing keys or very sparse recordings.
Structure includes per-layer stereo balance, random stereo spread and phrase rotation. Rhythm offers straight/triplet subdivisions and an internal metronome. Changing the grid leaves existing events intact; New rhythm uses the selected subdivision. Reroll pitch changes pitch without moving events. Cut exposes attack preference and detection sensitivity.
Output contains stereo-linked envelope compression with threshold, ratio, attack, release and makeup gain. It affects live output and exported music. Stem exports use the same full-mix sidechain envelope for every layer. The internal metronome is a separate synthesized click and is not exported. Fragment estimates and recording-key estimates are alternatives; key sync takes precedence when enabled. Voice reservations account for tails across loop boundaries. They reserve possible probability hits conservatively; skipping a hit does not create another event. MIDI interventions still share the physical 32-voice pool. Files remain linked to their original paths. Keep those paths available. Audio → Release unused decoded audio frees buffers no longer used by the active session; Keep/Undo reload source paths when recalled.

STEP EDITOR
Choose Step editor for the focused source-aware grid of your current collage. Click hits to reveal their inspector. Drag hits to move them in time; drag blank space or Shift-drag to select cells, including silence. Cmd-click adds cells. Velocity, gate, pitch, reverse and repeats apply to the whole selection. Green marks protection. Older rhythm-generation panels remain available through the additional tools. New instances load a starter kit automatically. Choose a style, choose a pattern length, then Generate and Play. Browse a WAV/AIFF to replace any sound, or drop a file onto its sample name. Play auditions the generated pattern, never a hidden reference recording.

GROOVE
Choose from thirteen starting vocabularies, including breakbeat, shuffle, two-step, electro, dub and slow crush. Lengths are 1, 2, 4, 8, 12 or 16 bars. Type BPM or use Tap.
New groove builds a fresh foundation, including short ghost doubles and triplet figures, then applies the current Pocket, Drunkenness and Glitch settings. New variation reshapes the current input using those same controls; repeated clicks reroll rather than multiply the previous damage. Advanced adjusts the same shared settings. Sliders alone do not rewrite notes. Set Pocket, Drunkenness and Glitch to zero for an untreated foundation.
Select/edit lets you drag over filled OR empty cells. Cyan cells show the time-and-lane generation area; Cmd-click adds/removes cells. Select bar selects all lanes in the visible bar. New groove and New variation respect that area, target lane, and explicit protection. Clear selection returns to whole-pattern scope. Playing / Viewing identifies the sounding and displayed bar; Follow changes the viewed bar with playback.
Keep base saves the current rhythm as a shaping base; Restore base restores it. New fill shapes the ending or selected area. Develop phrase requires Whole pattern scope and at least four bars, retaining the first-bar motif and building answers/fills. Undo restores the preceding musical edit.

EDIT
Choose Add/remove for one-click note on/off. Edit hit selects without altering a note; Previous/Next hit reaches overlapping hits. Choose Repeats and click a step to cycle 1 → 2 → 3 → 4 → 1. Three means a triplet burst inside that sixteenth-note cell. Numbers in cells count their hits. 3T labels an evenly spaced three-hit group; foundation triplets may span two cells, with a bracket. Note bars show actual time positions rather than evenly redistributing off-grid hits; they do not indicate velocity or MIDI pitch.
Select/edit opens the inspector without changing notes. Cmd-click adds or removes steps from a selection; dragging selects a rectangle of steps. The velocity strip sets all selected hits to a value from 1–127; +/− changes them relative to their existing accents. Pitch, gate, reverse and choke edits apply to the full selection, excluding protected hits. Move to lane reassigns the selection. The grid shows velocity height, repeat subdivisions, gate lengths, reverse arrows and protection marks. Reverse changes that hit, not the lane sample. Tools → Develop patterns → Reverse chance lets generated damage reverse unprotected non-anchor hits. It starts at 0%.
Move lets you drag selected hits together; Option-drag copies them. Their velocity, microtiming, pitch, gate, reverse, choke, envelope and sample overrides travel with them. Protected, occupied or out-of-range destinations cancel the whole move. Cyan outlines preview valid destinations; red outlines indicate a blocked move. The inspector’s −5 ms / +5 ms buttons nudge the full selection.
Edit menu offers an empty pattern (keeping the kit), select bar/all, copy, cut, paste, duplicate selection, duplicate bar, clear bar and redo. For paste, click the destination grid cell first, then Paste. Duplicate selection places its copy immediately afterward; Duplicate bar inserts a bar and shifts later notes, drawn regions and protected gaps together. Clear bar keeps protected material. Undo/Redo restores musical edits; a new edit clears redo history.
Protect locks hits or an empty step. Shift-click the first and last steps of a passage, then protect it in Develop patterns. Protection includes silence. Variation scope also applies to the main damage controls.

SOUND / INTERRUPTION
Tools → Hit envelope has attack/release, looped sustain, flutter, drawn gate levels and low/high-pass filtering. Sustain loops the chosen sample region with short crossfades; it is limited to 16 seconds per hit.
Tools → Draw interruptions provides per-role and whole-kit regions independent of note timing. Draw a region, drag either edge, then set depth, attack, release, curve and effect. Effects: mute/duck, low-pass, high-pass, bit crush, drive, flanger, delay and a short feedback reverberation. These are original lightweight processing algorithms, not copies of another plugin. Effects operate inside the existing tail; draw/sustain enough audio to hear them. Explicit locks are exempt; kick/snare attack protection is optional.
Click an instrument card to choose the target for the shared Browse, Hear, Candidate folder and Previous/Next controls. Candidate replacement keeps the pattern playing; Level match compensates using a short RMS/peak estimate rather than a perceptual loudness model.

+ Instrument adds up to six extra foley lanes (12 instruments total), each with its own sample and MIDI note. Core/Extra instruments switches the visible bank. Extra lanes use MIDI 127 downwards; Recast refuses to take a note already used by a saved rendered sound. New-lane generation uses an alternating percussion phrase.

Samples support gain, pitch, preparation/trim, normalization, candidate folders, in-context replacement, saved sound sets and library filtering. Pitch is tape-style; changing it changes speed/duration. Separate granular stretching is a texture tool, not transparent time correction.

COMPARE
Compare keeps your working groove alongside Pocket, Broken and Space alternatives. Choosing a version queues it for the next bar during playback. Preview matching only turns louder estimates down. Keep commits the chosen version; Undo returns to the preceding groove. Regenerate changes one alternative while retaining the others. Your working pattern is the export source until you Keep a comparison.

IDEAS
Tools also contains saved grooves, saved fragments, A/B comparison, alternative takes, voice/bass phrases, arrangement, collection and relinking. Saved grooves retain sounds and settings. Use selected-passage protection to preserve an idea while developing its surroundings.

MIDI / AUDIO
Send / Export → Editable MIDI to Live creates a clip in an empty Session slot on the same track; it does not overwrite existing clips. Six fixed role notes: kick 36, snare 38, hat 42, perc 39, texture 46, bass 43. Variation-family clips use the same mapping. Set Live to the intended BPM for host playback.
Ordinary role MIDI carries timing, velocity and note length. It does NOT encode reverse, per-hit pitch, drawn filters, audio interruption envelopes or other rendered processing. Render audio to retain the complete sound. Recast audition/WAV includes its internal processing, not downstream effects in Live. Use Live recording/freezing for those.
Send / Export also offers Rendered-sound MIDI to Live. This freezes each distinct processed sound onto an additional MIDI note in the same Recast instrument. These notes avoid the six role pitches, so ordinary and rendered-sound clips coexist. Reverse, pitch, envelopes and drawn interruption processing are baked into these sounds. Changing a MIDI note changes which frozen sound plays; edit a sound in Recast and write a new clip to change its processing. The bank holds up to 122 distinct rendered sounds per instance, reduced by extra instrument lanes. Exported MIDI note numbers stay pinned across layout changes. A Keep that would take over a reserved note is refused; use a new Recast instance for that layout. Save your Live Set or Recast session to retain that bank.
Editable kit export writes six role samples with the matching fixed-note MIDI and a note-map JSON; sample filenames include their actual note numbers. Load each sample onto that named Drum Rack note. Detailed pad export instead uses individual rendered sound combinations and its accompanying sequential MIDI mapping; it is separate from the six fixed-note handoff. Drum Rack import is manual, not automatic. Pitched phrase export intentionally creates a separate MIDI track for another instrument.

SAVE
Save the Live Set to retain device state. Save/Open also provides JSON session backups. Audio is linked to its file paths; it is not embedded. Collect/relink copies referenced audio with a session for relocation. Keep source files available until collection is complete.

VERIFICATION / LIMITS
Generated playback and fixed-role MIDI playback have produced real audio in Live. MIDI note timing, velocity and durations have been read back and compared. A host save/open test restored the kit, events, reverse probability and interruption regions; WAV tests confirmed a drawn mute becomes silence. Regression suites cover timing bounds, locks, repeats, scoped generation, DSP effects and editing.
This is a test build. Not every advanced UI combination or dialog has had a complete interactive pass. There are thirteen starting style families, six core roles and a 1024-hit pattern limit. No claim is made of complete parity with Choke or of a subjective guarantee that every generated rhythm will be musical.

HANDOFF CHECKPOINT
Rendered-sound MIDI uses a separate persistent note bank rather than clip-ID guessing. Ordinary kit clips keep their original role notes. This avoids first-note races when starting a clip and does not depend on the currently selected clip.
The Live handoff test captured repeated note playback with the rendered bank active for every note, including the first. The gate region was silent in both bounce and MIDI-driven capture. Editable kit export was checked for six correctly mapped, 44.1 kHz / 16-bit WAVs.

DRUM RACK READY EXPORT
Send / Export → Drum Rack ready kit + MIDI writes eleven WAV pads for notes 36 through 46, plus fixed-role MIDI and a note-map JSON. Select only that export's WAVs, sort by filename, and drop them together onto C1 in an empty Drum Rack. Silent EMPTY files fill unused notes so the six role assignments line up without placing sounds individually. Do not hold Command while dropping; Live uses that modifier for layering. Creating/loading the empty Drum Rack is still manual. This exports the editable role kit; use rendered-sound MIDI or WAV for per-hit processing.
Reference: https://www.ableton.com/en/manual/instrument-drum-and-effect-racks/#pad-view

RELIABILITY CHECKPOINT
Installed builds disable development hot reload. A new native picker action clears any canceled relink, collect or candidate-folder destination before opening. Audio exports check for a groove and assigned sounds before opening a destination picker. Replacing a role's sample updates both the playing pattern and its generation bases while retaining protected sounds. The retired reference-waveform drop areas are hidden.

RECALL
Live Set recall accepts native Dict objects and dictionary-name messages. Sampler initialization retries while parent buffers are loading; unavailable audio is reported for relinking. The current rebuild has passed a read-only save/unload/reopen check for event state, extra instruments, comparison options, rendered-note bank and loaded sample buffers.

INTERFACE
The shared interface uses charcoal panels, restrained amber highlights, DIN/Helvetica typography, cached kit waveform thumbnails and hover explanations. Instrument target, time scope, gate duration and choke group use explicit menus. Full sample removes a gate-length override. The compact Open Recast control is exposed to Live accessibility; zero/initialization messages do not open the workshop.

DETAILED COMPARISON
The comparison cards show the same bar across all four versions, with bar navigation and a whole-phrase overview. Gray reference ticks show Current; hit height shows velocity; horizontal tails show explicit gates; blue lines show timing shifts; < marks reverse. Six core roles have separate rows, with extra instruments grouped under +FOLEY. Change summaries count additions/removals, timing moves, accents, gates, direction and pitch across the full pattern. Matching is an estimate. Protected material is reconciled during audition as well as Keep. Broken adds non-timing disruption when the target permits it; Space removes detail while preserving the foundation. Zero controls or a fully protected target can correctly produce an unchanged alternative.

ACCEPTANCE FIXES
Assigned samples no longer require legacy reference-slice data to play, including a new extra lane created before main-kit generation. Level match Off survives session recall. Editable MIDI uses processed sample duration for extra instruments, retains short gates and applies cross-lane choke limits. Role MIDI still cannot reproduce arbitrary audio processing; use rendered-sound MIDI or WAV for that.

SAMPLE POOLS
Click Pools in the main header. Choose a lane and Add sample (WAV / AIFF); up to 16 sounds belong to each lane. Add current lane sound includes the existing one-shot. Round robin cycles in order. Weighted chance draws independently with relative weights: 300 is three times as likely as 100; 0 excludes a sound. Use all / no repeat consumes every enabled sound before another shuffled bag and avoids immediate repeats across bag boundaries. Pool-only lanes can play without a separate base sample. Each lane still has its own MIDI note. Disabled/all-zero pools fall back to the lane sample, if one is assigned.
Replacing/removing pool entries does not delete audio. Pools, weights and modes are saved with the session and participate in undo. Existing explicit per-hit sources and frozen sounds retain their source; protected pool-only notes use an available fixed choice.

TENSION / RELATIONSHIPS
Movement opens a 16-point phrase-wide tension curve. Draw to build and release pressure; depth and target are independent. Tension shortens gates, shifts timing, introduces omissions, bursts and occasional reverse while retaining foundation/locked hits and protected gaps. It reshapes playback without rewriting the working grid.
Up to four relationships connect a trigger lane with another lane: Duck shapes its tails during a chosen window; Answer adds a quieter delayed reply; Interrupt cuts a tail at the trigger. Source, target and behavior use visible menus. An answering lane needs a sample or pool. Changes can be frozen into editable notes.

MALFUNCTION
While playing, hold HOLD: MALFUNCTION on the Movement screen. The effect grows while held; release recovers on the next beat or bar. Choose its target there. Record gesture stores quarter-beat control segments for subsequent passes (up to 64 segments); Clear recorded gestures removes them. Heavy anchors and explicit protections remain intact. The exact triggered result can be kept through recovery. It is not a recording of downstream Live FX.

RECOVER / FREEZE
Recover retains up to 32 bars / 4096 triggered hits while the device is loaded. Last bar / 2 / 4 / 8 recovers completed bars on their original grid; if fewer complete bars exist, the available passage is retained. Recovered notes include chosen sources, movement and interruption settings; they are editable and undoable. This rolling history is temporary and clears on a new playback or session load.
Freeze performance keeps the current realization’s sample choices and movement as fixed notes. For an evolving live gesture, Recover is the way to retain what was actually heard. Freeze uses the current pass, not a freshly randomized export. Exports direct you to Freeze first whenever live pools/movement are active; Send / Export also has a Freeze button. Undo restores the live setup. Frozen notes do not follow subsequent pool changes; regenerate or undo the freeze to return to live choices.
Rendered-sound MIDI or WAV retains the exact frozen sound. Editable role MIDI retains rhythm and one note per lane; a live pool can choose new samples when those notes play. Editable base-kit export does not encode an entire multi-sample pool.

DIRECT GRID EXPRESSION
Edit menu → Tool: drag gate lengths: drag a filled step horizontally; the selection changes together. Gate tails appear on the grid. Tool: paint velocity: vertical position within a row sets the selected accents; drag through filled cells to paint others. Tool: stretch selected burst: select hits first, then drag horizontally to compress/expand their relative timing and explicit gates. Each gesture is one undo. Protected/occupied/out-of-bounds destinations block stretching. Frozen interruption regions travel with moved, copied and stretched hits.

The main grid adds beat dividers, a moving playhead and a small per-bar density overview. The new functions use dedicated Pools, Movement and Recover screens to keep the editor focused. Dense DSP and newly encountered sample/effect combinations can still require preparation; no hard real-time timing guarantee is made.

BETA 3 WORKFLOW
Browse now opens the integrated sample browser. Choose your library folder once; then browse folders or search filenames. A single file click previews it. Assign commits to the chosen lane; Add to pool adds a candidate to its sample pool. In groove auditions a candidate temporarily while the pattern plays. Returning to the pattern cancels that audition.

Generate creates a new foundation; Another take develops the existing base. Pocket and Damage reroll a treatment instead of accumulating more subdivisions. Lane pockets sets independent offset, swing, timing spread and accents. Lock the kick there to regenerate around it. New malfunction changes a selected passage or a 4/8/16-step window and leaves the surrounding groove alone.

Select one or several steps and open Gate. One step is a sixteenth note; choices include 1, 3 and 16 steps. Full sample removes the gate. Gates limit playback; short samples need sustain to play longer. Choke rules can shorten a tail. Fixed-role MIDI retriggers one voice per lane; use rendered audio or rendered-sound MIDI for overlapping tails.

BETA 4: BROWSING AND INSTABILITY
The sample browser has folders on the left, a scrolling file list in the middle, and preview/assignment on the right. Back/Forward remember folder visits; Up and the path buttons navigate parents. Single-click previews, double-click assigns; neither changing folders nor previewing changes your kit. Favorites are limited to your chosen library. Search scans WAV/AIFF filenames within that library; very large libraries can take time to index. Scrollbars and mouse/trackpad scrolling move through the lists.

Main Drunkenness controls timing; Glitch controls structural disruption. New variation applies the current settings to variable-length episodes of stumble/recovery, missing hits and late answers, shaped bursts, interruptions, shifted fragments and breakdowns. Settings opens four common sliders; expand Behavior mix for relative behavior likelihoods (zero disables a family) and gate tightness. Detail bias favors hats/perc/textures; anchor protection preserves generated kick/snare anchors. Explicit locks and protected silence always win. Consecutive New variation clicks reroll from the same input instead of recursively multiplying repeats.

Feel / instability now uses direct sliders: Timing sway, Late lean, Uneven repeats and Tail cutting. More feel controls expands the detailed settings. Select which lanes should stay steady, adjust controls, then Generate a new take. Use current as input deliberately establishes a new base; Make space generates a sparser result. These are settings for generating fixed editable notes, not live automation knobs.

Hover buttons or slider labels/tracks for explanations in the bottom-left footer. Leaving a control restores the ordinary status message.

BETA 5: MUSICAL FOUNDATIONS
The style dropdown now has 13 foundations, each with a short description: Broken funk, Half-time weight, Driving syncopation, Straight backbeat, Four to the floor, Electro breaks, Two-step, Dub space, Slow crush, Motor pulse, Tresillo, Shuffle and Breakbeat. Selecting one does not replace your notes; Generate creates a new foundation. All remain 4/4.

The added grammars coordinate fixed kick cores, optional syncopated kick choices, backbeats, quieter snare ghosts, hat subdivisions/accents and restrained phrase endings. A main motif recurs with an answering bar. Shuffle writes its long/short timing into the notes; it is not only a label or an audio effect. Breakbeat favors syncopated kicks, more ghosts and accented hat detail. Detail scales optional activity. Drunkenness, Glitch, step editing, sample pools and MIDI output work on every foundation. Use protection to retain the foundation while damaging the details.

These are authored musical rules, not a trained AI or a comprehensive representation of each named genre. The original three saved style indices are unchanged.

BETA 6: IMMEDIATE PLAYBACK
New instances automatically assign a small original synthesized starter kit: Kick, Snare, Hat, Metal, Relay and Bass. Choose Generate, then Play without browsing first. All six are 16-bit / 44.1 kHz mono WAVs, included under the project MIT license. Replace any sound normally. No extra UI or network download is needed.
Keep Starter Kit beside Recast.amxd. The build generates these assets from tools/make_starter_kit.py. Saved sessions retain their custom assignments and deliberately empty lanes. Starter-file references relink to the installed Starter Kit when the device is moved; custom sample references remain yours.
Automatic source restoration skips empty or missing paths and uses explicit import, avoiding unexpected file-picker fallbacks. Missing session audio remains available through Files / recovery.


SAMPLE BROWSER / ASSIGNMENT
Browse opens a folder tree, flat sample list and waveform preview. Choose Library folder once; expand folders with their triangle, or select a folder to see its samples. Back/Forward/Up and breadcrumbs navigate; the mouse wheel and scrollbars move long lists. Search + Enter searches your chosen library; Favorites retains useful files. Single-click previews; double-click or the amber Use button commits. In groove auditions a candidate during playback; leaving cancels that audition.
Target: entire lane replaces ALL hits on that lane, including previous frozen overrides on rhythmically protected hits, and disables its sample pool. Protection still protects rhythm during generation. Target: selected hits assigns only those selected events; it leaves the lane sample unchanged. The main grid marks explicit per-hit samples with S, and the sound summary identifies lane versus selected-hit audio. Empty selected cells have no sound to replace. To return a lane to one sample, choose Entire lane and assign it. Pool assignment remains a separate action under the lane pool tools.

LOCAL DRAW SETUP
Open Library draw setup from the collage page (also Audio > Layer folders / draw recipes). Choose global library folders, then optionally choose a separate folder and type hint per layer. Draw recipes fill those hints together. Keep sound protects a layer. Types use file/folder names; they are not an audio classifier. If there is no matching readable file, the existing sound stays. New sounds excludes active recordings, prefers fresh paths, and relaxes recent history only for small pools. Forget recent draws resets history. Rescan refreshes the index and WAV/AIFF duration metadata. Sources remain on disk and are never deleted.

SOUND CHARACTER AND COPIED FILES
Each draw layer can independently request low, bright, sharp/sparse, sustained or rough material based on short measured audio windows. Set its filename type to Any if filenames are unhelpful. Both filters apply when set. These are approximate sound descriptors, not voice or instrument recognition. Avoid copied files compares complete bytes against active source recordings and skips exact copies, even under another filename. Nothing is deleted. Retagged, re-encoded and near-identical recordings are not detected. The Draw button becomes Stop during preparation. Rescan clears descriptor and copy caches after files change in place. Unknown/compressed candidates still decode into memory before sound analysis.

REFINING A PHRASE
Choose Target before generating: Whole Pattern, Selected Layer, This Bar or a passage selected in Step editor. Locks win. Use 2+ bars for recurring motifs, replies and end fills; Structure > Phrase development sets the amount. New damage proposes bursts, dragging/rushing episodes, gaps, reversals, chokes and late answers from a stable base. Swap fragments keeps timing/treatment. Find new fragments keeps the hit pattern. Library draws keep the current rhythm by default; switch Keep rhythm off for a new phrase.
While playing, new proposals prepare separately and switch at the next ready bar. Stop cancels. Editing invalidates a stale proposal. Cold file decoding or heavy processing can still stall the JavaScript scheduler. Hear previous / Hear generated compares the last two phrases with approximate down-only audition matching; exports keep their own levels.
Edit / audition fragments opens a per-hit waveform and alternatives. It starts zoomed around the chosen region. Zoom in/out or choose Whole source; drag a boundary, then Apply. Other hits stay unchanged. Cyan markers and the status summary show changes. Output > Safety ceiling is on by default at -1 dB sample peak; it links stereo and stem gain and can be disabled. It is not a true-peak mastering limiter.
Local library roots are optionally remembered beside the device in LibraryPreferences.json. That private machine file is never included in releases.

UNIFIED GENERATION
Adjust the four main sliders, then click Generate to apply them together. It keeps your loaded sounds. Choosing a style fills the controls once; Generate respects subsequent adjustments. Amber text marks unapplied slider changes. More variations offers optional single-aspect rerolls. Each layer’s New sound draws a replacement while preserving its timing and the other layers. Library drawing shows scanning/loading feedback.

Density, Movement and Damage now have gentler travel: the midpoint gives one-quarter of the range, with full extremes still at the far right. Existing saved values keep their sound.

Send audio to Live offers Full loop (one new audio track) or Layer stems (one new track per layer). WAVs render into Recast’s Rendered folder and are inserted together in Arrangement at the beginning of the current playhead bar. Tracks are appended without replacing existing clips. Audio remains unwarped, retaining Recast’s timing; match Live’s BPM to Recast for bar-grid alignment. Use Live’s Collect All and Save to collect the linked WAVs into the Set. Editable rendered-sound MIDI remains available from the same menu.

Fragment editing includes a reverse switch, Keep this hit, and Apply + hear in pattern. Each layer’s Keep button protects its sound from library draws while allowing rhythm generation; Lock layer freezes the whole layer. Layer / sound → Material filter chooses short impacts, sustained machinery, voices, low drones, textures or drums using filename hints and approximate sound measurements. New sound applies that search. More variations includes Keep selected passage (all layers, including silence) and Release passage locks; kept hits appear green on the circular view.

LISTEN, TRY, KEEP
The main slider percentages match handle position while gentle response curves stay internal. The Hearing line names the current phrase; preparation and queued bar switches are identified separately. Rings are numbered outside to inside, skipping layers with no source. Click a dot for that hit’s fragment editor.
New sound on one layer replaces it directly and stays on the collage screen. Its Palette chooser selects the whole collection, a named palette, or the global palette. Browse still offers a reversible in-context audition with Original/Candidate, Keep, Try another and Cancel. Manual browser selection offers Preview in groove rather than silently committing the sample. The Library folder menu switches between configured roots. Rejected candidates are avoided until you finish that audition.
Recent takes keeps the last eight takes in this device instance. Switching while playing prepares first and lands on a ready bar. Return to working restores the phrase you had before comparison. Save any history entry into a Keep slot to retain it in a saved session. Recent history itself is temporary.

Library draws prepare against isolated state while the current phrase continues. Cold decoding can still cause scheduling delays. Index/descriptor caches are local, bounded, expire after one day and are ignored by Rescan. They are excluded from public archives.

KEEPER DEVELOPMENT AND PALETTES

Palette definitions persist in sessions and private local preferences.
More like this explores a stable home phrase. Develop / explore sets Distance and can adopt the current phrase as a new home. FOUNDATION / COHERENCE / WILDNESS
